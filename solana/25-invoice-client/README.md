# Занятие 25. Смарт-контракт на Rust и деплой в Solana, часть 2

Клиент для программы из [занятия 24](../24-invoice-program/): создаёт инвойс, оплачивает его и проверяет результат — всё через RPC.

## Что демонстрирует

- отправку транзакций в Solana через `solana-client` (RPC)
- построение инструкций, `Message`, подписание и отправку транзакции
- вызов программы: `CreateInvoice` (создание PDA админом) и `PayInvoice` (оплата с переводом lamports)
- airdrop на локальном валидаторе и ожидание подтверждения
- чтение данных аккаунта после выполнения

## Запуск

```bash
solana-test-validator
```

В другом терминале (ключ админа передаётся через переменную окружения — **не коммитьте ключи в репозиторий**):

```bash
export ADMIN_KEYPAIR="12,34,56,..."
cargo run
```

`ADMIN_KEYPAIR` — байты keypair-пары через запятую (как в `solana-keypair` JSON-массиве).
